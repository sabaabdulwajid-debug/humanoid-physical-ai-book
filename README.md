# Physical AI & Humanoid Robotics Textbook

This repository contains the complete documentation for the "Physical AI & Humanoid Robotics" textbook, built with Docusaurus.

## Project Overview

This comprehensive textbook covers the intersection of artificial intelligence and embodied systems, focusing on humanoid robots and their applications in various domains.

## Book Structure

The textbook is organized into seven main parts:

### Part 1: Foundations of Physical AI
- What is Physical AI?
- From Software Agents to Embodied Intelligence
- Human-Robot Collaboration
- Cognitive Architectures for Robots

### Part 2: Humanoid Robotics Fundamentals
- Anatomy of a Humanoid Robot
- Sensors and Actuators
- Locomotion and Balance
- Energy and Materials

### Part 3: Intelligence in the Body
- Robot Perception
- World Models and Spatial Reasoning
- Learning in the Physical World
- Multi-Agent Physical Systems

### Part 4: Physical AI Systems
- ROS2
- Simulation Environments
- LLMs with Robots
- Autonomous Planning

### Part 5: Applications
- Industry and Warehouses
- Healthcare Robotics
- Home and Social Robots
- Extreme Environments

### Part 6: Ethics and Governance
- Safety and Alignment
- Ethics of Humanoid Labor
- Regulation and Standards
- Human Dignity

### Part 7: Capstone and Future
- Designing a Physical AI Product
- The Future of Humanoid Robotics

## Technical Implementation

- Built with Docusaurus, a modern static site generator
- Complete documentation structure with proper sidebar navigation
- All content organized in the `docs/` directory
- Responsive design for all device sizes

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser to `http://localhost:3000` to view the documentation.
